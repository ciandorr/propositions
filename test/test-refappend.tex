\section{Parentref in ref format with a custom numbered style}

Sub-items of a \texttt{P} item use the default level-two style, whose
\texttt{ref format} is \verb|\parentref{#1}|, so their references carry the
parent's name.

\begin{prop}
  \item[style=P] Premise One is a two-part premise. \label{P1}
  \begin{prop}
    \item The first part is called part a. \label{P1a}
    \item The second part is called part b. \label{P1b}
  \end{prop}
  \item[style=P] Premise Two is straightforward. \label{P2}
\end{prop}

References: \ref{P1}, \ref{P1a}, \ref{P1b}, \ref{P2}.

Expected: (\textbf{P1}), (\textbf{P1a}), (\textbf{P1b}), (\textbf{P2}).

\section{The \texttt{ref} key on a style declaration}

The \texttt{ref} key bakes the parent prefix into the ref \emph{text} (not the
format), so \verb|\nref| returns the full hierarchical name.

\DeclareNumberedStyle{newinner}[
  counter format = \alph{newinner},
  display format = #1.,
  ref            = {\nparentref\alph{newinner}},
  ref format     = {(#1)}]

\begin{prop}
  \item Outer item. \label{outer}
  \begin{prop}
    \item[style=newinner] Subitem. \label{sub1}
    \item[style=newinner] Second subitem. \label{sub2}
  \end{prop}
\end{prop}

Ref: \ref{sub1} (expected: (3a)).

Nref: \nref{sub1} (expected: 3a).

Ref outer: \ref{outer} (expected: (3)).

\section{Four ways to derive a subitem's reference}

\DeclareNumberedStyle{inner}[
  counter format = \alph{inner},
  display format = #1.]

\begin{prop}
  \item[OI] Outer item. \label{outer2}
  \begin{prop}
    \item[style=inner, format=\parentref{.#1}] \label{dsub1}
      \texttt{format}: \ref{dsub1}, naked \nref{dsub1}.
    \item[style=inner, display format=#1., ref format=\parentref{.#1}]
      \label{dsub2}
      \texttt{ref format}: \ref{dsub2}, naked \nref{dsub2}.
    \item[style=inner, name={\nparentref.\alph{inner}}] \label{dsub3}
      \texttt{name}: \ref{dsub3}, naked \nref{dsub3}.
    \item[style=inner, ref={\nparentref.\alph{inner}}] \label{dsub4}
      \texttt{ref}: \ref{dsub4}, naked \nref{dsub4}.
  \end{prop}
\end{prop}

Expected refs: \texttt{OI.a}, \texttt{OI.b}, \texttt{OI.b}, \texttt{OI.c}.  The
\texttt{name} and \texttt{ref} variants put the prefix into the naked form too;
\texttt{format} and \texttt{ref format} do not.  Note that the third item
repeats the second's letter: an explicit \texttt{name} suppresses the counter
step, so \texttt{ref} is the key to use for a derived reference that should
still count.

\section{Titlecase reference commands}

\DeclareNumberedStyle{TC}[ref format=(\textbf{#1})]

\begin{prop}
  \item[style=TC, name={Identity Theory}, ref format={(\textbf{the #1})}]
    Mental states are physical states. \label{tc:id}
  \item[style=TC] A plain numbered TC item. \label{tc:num}
  \begin{prop}
    \item Sub-item a. \label{tc:sub}
  \end{prop}
  \item[style=TC, name={Identity Theory}, ref format={\textbf{the #1}}]
    The same, with no bracket before the name. \label{tc:nopar}
  \item[test, style=TC] A named TC item with a lower-case name. \label{tc:lower}
  \begin{prop}
    \item Sub-item a. \label{tc:lowersub}
  \end{prop}
\end{prop}

The titlecase commands uppercase the first character of the output and nothing
else, so a \texttt{ref format} that opens with a literal `(' leaves them with
nothing to do: through this style they match their plain counterparts exactly.
Before that was settled they looked ahead for the first \emph{letter} however
far in it was, which made a reference reading `(2a)' come back as `(2A)'.  A
leading \emph{command} is no obstacle---see \verb|tc:nopar| below.

Ref: \ref{tc:id} (expected: (\textbf{the Identity Theory})).

Ref (titlecase): \Ref{tc:id} (expected: (\textbf{the Identity Theory})---the
`(' comes first, so there is nothing to uppercase).

Ref* (titlecase, no link): \Ref*{tc:id} (expected: the same, unlinked).

Nref: \nref{tc:id} (expected: Identity Theory).

Nref (titlecase): \Nref{tc:id} (expected: Identity Theory).

Oref: \oref[$'$]{tc:id} (expected: (\textbf{the Identity Theory$'$})).

Oref (titlecase): \Oref[$'$]{tc:id} (expected: (\textbf{the Identity
Theory$'$})).

Lastref: \lastref{} (expected: (\textbf{test})---the sub-list's items are
local to it, so once it has closed \verb|\lastref| again refers to the last
item of the enclosing level).

Lastref (titlecase): \Lastref{} (expected: (\textbf{test})).

Nested ref (titlecase): \Ref{tc:sub} (expected: (\textbf{TC1a})).

Lower-case names: \Ref{tc:lower} (expected: (\textbf{test})),
\Ref{tc:lowersub} (expected: (\textbf{testa})).

No leading bracket: \ref{tc:nopar} (expected: \textbf{the Identity Theory}),
\Ref{tc:nopar} (expected: \textbf{The Identity Theory}---a leading command is
no obstacle, only a leading character).

\section{Alignment: left, right, center}

Labels of varying width show the difference.  Right-aligned labels are flush
against the item text (like standard \texttt{enumerate}); left-aligned labels
start at the left of the label box; centered labels are centered in it.

\begin{prop}
  \item[name={A},   align=right]  Right-aligned short label.
  \item[name={BB},  align=right]  Right-aligned medium label.
  \item[name={CCC}, align=right]  Right-aligned long label.
  \item[name={A},   align=left]   Left-aligned short label.
  \item[name={BB},  align=left]   Left-aligned medium label.
  \item[name={CCC}, align=left]   Left-aligned long label.
  \item[name={A},   align=center] Centered short label.
  \item[name={BB},  align=center] Centered medium label.
  \item[name={CCC}, align=center] Centered long label.
\end{prop}

\section{Alignment: nextline variants}

\begin{prop}
  \item[name={Short label}, align=nextline]
    Nextline with a short label (starts at the default label position).
  \item[name={A much longer label that should demonstrate how the nextline
    option lets labels wrap across multiple lines when they are awkwardly
    long}, align=nextline]
    Nextline with a long wrapping label.
  \item[name={Short label}, align=nextline, labelindent=0pt]
    Nextline with \texttt{labelindent=0pt} (starts at the left margin).
  \item[name={A much longer label that should demonstrate how the nextline
    option with labelindent=0pt lets labels wrap across multiple lines when
    they are awkwardly long}, align=nextline, labelindent=0pt]
    Nextline with \texttt{labelindent=0pt} and a long wrapping label.
  \item[name={Short label}, align=flush-nextline]
    Flush-nextline with a short label (starts at the item text margin).
  \item[name={A much longer label that should demonstrate how the
    flush-nextline option lets labels wrap across multiple lines when they are
    awkwardly long}, align=flush-nextline]
    Flush-nextline with a long wrapping label.  Some more text, to see what
    happens at the start of the item body.
  \item[name={N}, align=left] Normal left alignment, for comparison.
\end{prop}

A nextline label ends by starting the item's paragraph, so unlike every other
alignment the space that follows \verb|\item[...]| in the source is typeset
rather than dropped in vertical mode.  All four bodies below must begin at the
same x, whether or not there is a space after the bracket.

\begin{prop}
  \item[{Nextline, with a space}, align=nextline] body begins here.
  \item[{Nextline, no space}, align=nextline]body begins here.
  \item[{Flush-nextline, with a space}, align=flush-nextline] body begins here.
  \item[{Flush-nextline, no space}, align=flush-nextline]body begins here.
\end{prop}

\section{Continuing sub-item lettering with \texttt{reset=false}}

Processing an \verb|\item| resets the counter of the level below it, so a sublist
opened under a fresh outer item normally restarts at~\texttt{a}.  With
\texttt{reset=false} on that outer item the lettering carries on instead, which
is what is wanted when commentary interrupts a list of clauses.

\begin{prop}
  \item[style=P] Multi-clause definition. \label{mcd}
  \begin{prop}
    \item Clause one. \label{cl1}
    \item Clause two. \label{cl2}
  \end{prop}
\end{prop}

Commentary on why these clauses are not enough, and we also need:

\begin{prop}
  \item[reset=false]
  \begin{prop}
    \item Clause three: continues at c. \label{cl3}
  \end{prop}
\end{prop}

More commentary, this time under an unlabelled outer item:

\begin{prop}
  \item[counter=none, reset=false]
  \begin{prop}
    \item Clause four: continues at d. \label{cl4}
  \end{prop}
\end{prop}

And without \texttt{reset=false}, for contrast:

\begin{prop}
  \item[counter=none]
  \begin{prop}
    \item Back to a. \label{cl5}
  \end{prop}
\end{prop}

References: \ref{mcd}, \ref{cl1}, \ref{cl2}, \ref{cl3}, \ref{cl4}, \ref{cl5}.

Expected: (\textbf{P5}), (\textbf{P5a}), (\textbf{P5b}), (\textbf{P5c}),
(\textbf{P5d}), \texttt{a}.

All four clauses answer to \textbf{P5}, though only the first two sit in a
list under it.  An item carrying \texttt{reset = false} continues its
predecessor's sub-numbering rather than starting afresh, so it does not become
the parent of the sub-list that follows it: the run belongs to whatever it
began under.  Taking each intervening item as the parent instead would give
\texttt{P5a}, \texttt{P5b}, \texttt{6c}, \texttt{6d}, whose letters answer
to one parent and whose prefixes to another.  It makes no difference whether
the intervening item is labelled --- clause three's is numbered \texttt{6},
clause four's is unlabelled --- since what matters is that the count carries
on.

The final list has no \texttt{reset = false}, so it does start afresh, and its
item duly becomes the parent.  That parent is unlabelled, so the reference is
bare \texttt{a}: a fresh run under an unlabelled item has no prefix to offer,
which is the honest answer and keeps it from colliding with clause one.
\texttt{[style = nolabel, reset = true]} is the way to ask for exactly this.
