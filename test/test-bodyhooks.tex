\newcommand\probe{OUT}

%% body begin / body end: material at either end of an item's body.
%%
%% An item's body is not an argument -- it runs to the next \item or to the end
%% of the environment -- so the group it is put in has to be closed from a
%% distance, at the head of the next item and in the environment's end code.
%% That is the machinery beamer's overlay specifications also use.
%%
%% Nothing is opened for an item whose style asks for neither key, so an item
%% that wants no group does not get one.

  \item Upright body: an item whose style asks for neither key opens no group.
  \item[style=ital] Italic again.
\end{prop}

\section{A nested list is inside its parent item's body}

\begin{prop}[body begin = \bfseries]
  \item Bold body.
  \begin{prop}
    \item This sub-item is inside the outer item's body, so it inherits the
      bold.  A style for the inner level would have to set its own
      \texttt{body begin} to get out of it.
  \end{prop}
  \item Bold again.
\end{prop}

\section{A level-dependent body font}

\makeatletter
\DeclareRobustCommand\wt{[\f@series]}
\makeatother

\verb|\proplevelchoice| is expandable and reads the nesting level where it is
used, so it can stand in a \texttt{body begin}: the first entry applies at level
one, the last at every level from its position down.  Each body below reports
its own weight, and each label reports the label's.

The environment argument is the wrong place for it.  It reaches the items in
this environment's immediate scope and no further, which is the same rule that
already sends \texttt{style\,=\,hierarchical} to \verb|\propoptions| rather than
here.  The inner levels get no \texttt{body begin} of their own, so they stay
inside the level-one group and come out bold --- and, the style not having
reached them either, they are numbered by the default \texttt{numbered} style
rather than hierarchically.  This is the expected result, not a fault:

\begin{prop}[style=hierarchical, body begin=\proplevelchoice{\bfseries,\mdseries}]
  \item Level one \wt.
  \begin{prop}
    \item Level two \wt: bold, and lettered rather than hierarchical.
  \end{prop}
  \item Level one again \wt.
\end{prop}

Set through \verb|\propoptions| it cascades, and both the numbering and the
weight come out by level:

{\propoptions{style=hierarchical, body begin=\proplevelchoice{\bfseries,\mdseries}}
\begin{prop}
  \item Level one \wt: bold.
  \begin{prop}
    \item Level two \wt: medium.
    \begin{prop}
      \item Level three \wt: medium, the last entry standing for every level
        from its position down.
    \end{prop}
  \end{prop}
  \item Level one again \wt.
\end{prop}}

Note that the level-one \emph{label} is not bold.  Labels normalise weight and
shape whatever the body around them does, so a bold body does not drag its own
label into bold; a style that wants both would set \texttt{display format} or
\texttt{label format} as well.
