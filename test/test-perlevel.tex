\documentclass{article}
\usepackage{calc}           % for \widthof
\usepackage{propositions}

%% Level-varying dimensions.  A dimension key's value is stored unexpanded and
%% evaluated where it is used, so \proplevelchoice in it resolves at the level
%% being set up; and the sentinel * means "as if the key had not been set" --
%% inherit the class default, or leave the dimension free for the label-area
%% resolver.  This file reports the dimensions the list actually ends up with,
%% so the expectations can be checked without measuring the page.

\newcommand\report{\texttt{LM=\the\leftmargin, LW=\the\labelwidth,
  LS=\the\labelsep}}

%% Print the width of some text (\widthof is only usable in a calc expression).
\newlength\testwd
\newcommand\wid[1]{\setlength\testwd{\widthof{#1}}\the\testwd}

\begin{document}

\section{Class defaults (baseline)}

\verb|\leftmargini| = \the\leftmargini, \verb|\leftmarginii| =
\the\leftmarginii, \verb|\leftmarginiii| = \the\leftmarginiii.

With no options set, each level should use the class default for its depth.

\begin{prop}
  \item Level 1: \report
  \begin{prop}
    \item Level 2: \report
    \begin{prop}
      \item Level 3: \report
    \end{prop}
  \end{prop}
\end{prop}

\section{A level-varying value via \texttt{\textbackslash propoptions}}

\verb|leftmargin=\proplevelchoice{3em, 1em, *}|: level 1 is 3em and level 2 is
1em.  Level 3 takes the sentinel, so it falls back to the class default
(\the\leftmarginiii).  Without that third entry level 3 would repeat the last
one, since \verb|\proplevelchoice| clamps to its final entry rather than
running out.

\begingroup
\propoptions{leftmargin=\proplevelchoice{3em, 1em, *}}
\begin{prop}
  \item Level 1 (expect 3em): \report
  \begin{prop}
    \item Level 2 (expect 1em): \report
    \begin{prop}
      \item Level 3 (expect \the\leftmarginiii): \report
    \end{prop}
  \end{prop}
\end{prop}
\endgroup

Without the sentinel the last entry carries on downwards, which is the other
half of the contrast:

\begingroup
\propoptions{leftmargin=\proplevelchoice{3em, 1em}}
\begin{prop}
  \item Level 1 (expect 3em): \report
  \begin{prop}
    \item Level 2 (expect 1em): \report
    \begin{prop}
      \item Level 3 (expect 1em, repeated): \report
    \end{prop}
  \end{prop}
\end{prop}
\endgroup

\section{The sentinel skips a level}

\verb|leftmargin=\proplevelchoice{*, 0em}|: level 1 takes the class default
(\the\leftmargini), level 2 is 0em, so level-2 text aligns with level-1 text.

A \emph{blank} entry would not do this.  \verb|\proplevelchoice| reads its
argument as a comma list, and comma lists discard empty items, so
\verb|\proplevelchoice{, 0em}| would put 0em at level 1.  That is what the
sentinel exists for.

\begingroup
\propoptions{leftmargin=\proplevelchoice{*, 0em}}
\begin{prop}
  \item Level 1 (expect \the\leftmargini): \report
  \begin{prop}
    \item Level 2 (expect 0.0pt): \report
  \end{prop}
\end{prop}
\endgroup

\section{A bare sentinel is the same as not setting the key}

\verb|leftmargin=*| at every level must reproduce the baseline of section~1
exactly.

\begingroup
\propoptions{leftmargin=*, labelwidth=*, labelsep=*}
\begin{prop}
  \item Level 1: \report
  \begin{prop}
    \item Level 2: \report
    \begin{prop}
      \item Level 3: \report
    \end{prop}
  \end{prop}
\end{prop}
\endgroup

\section{Per-level \texttt{labelwidth} sized to the widest label}

\verb|labelwidth=\proplevelchoice{\widthof{(99)}, \widthof{a.}, \widthof{(iii)}}|
gives each level just enough room for its own widest label.  The values are
\textsf{calc} expressions, which the resolver has to leave intact.

\begingroup
\propoptions{labelindent=0pt,
  labelwidth=\proplevelchoice{\widthof{(99)}, \widthof{a.}, \widthof{(iii)}}}
\begin{prop}
  \item Level 1 (expect LW=\wid{(99)}): \report
  \begin{prop}
    \item Level 2 (expect LW=\wid{a.}): \report
    \begin{prop}
      \item Level 3 (expect LW=\wid{(iii)}): \report
    \end{prop}
  \end{prop}
\end{prop}
\endgroup

\section{Per-level \texttt{labelindent}}

\verb|labelindent=0em| at every level: the label starts at the enclosing
margin, so sub-item labels sit in the gap left by the outer label while the
sub-item text keeps the class-default indent.

\begingroup
\propoptions{labelindent=0em}
\begin{prop}
  \item Outermost item, labels flush with the enclosing margin.
  \begin{prop}
    \item Sub-item a: label in the gap, text indented.
    \item Sub-item b: same layout.
  \end{prop}
  \item Another outermost item, confirming dimensions are restored.
\end{prop}
\endgroup

The original mockup layout:
\verb|labelindent=\proplevelchoice{0em, -1.5em}| pushes level-2 labels left
into the gap, and \verb|leftmargin=\proplevelchoice{3em, 0em}| zeroes the
level-2 margin so level-2 text aligns with level-1 text.

\begingroup
\propoptions{labelindent=\proplevelchoice{0em, -1.5em},
  leftmargin=\proplevelchoice{3em, 0em}}
\begin{prop}
  \item Outermost item.  The level-two text below should align with this text.
  \begin{prop}
    \item Sub-item one: its text aligns with the level-one text above, and its
    label sits to the left, in the gap where the outer label was.
    \item Sub-item two: confirming alignment.
  \end{prop}
  \item Another outermost item, confirming level-one layout is unaffected.
\end{prop}
\endgroup

\section{A level-varying value in an environment argument is env-local}

An argument styles only its own environment, so the nested list below falls
back to the class default rather than picking up the second entry.

\begin{prop}[leftmargin=\proplevelchoice{3em, 1em}]
  \item Level 1 (expect 3em): \report
  \begin{prop}
    \item Level 2 (expect \the\leftmarginii, not 1em): \report
  \end{prop}
\end{prop}

With \verb|\propoptions| the same value does cascade, as in section~2 above.

\section{The sentinel works inside a style}

This is what the old comma-list syntax could not do: a style's dimension keys
are read twice, once for the list's geometry and once for each item's label
area, and the per-item reading passes the value straight to \verb|\setlength|.

\begingroup
\SetPropStyle{levelvarying}{leftmargin=\proplevelchoice{3em, *}}
\propoptions{style=levelvarying}
\begin{prop}
  \item Level 1 (expect 3em): \report
  \begin{prop}
    \item Level 2 (expect \the\leftmarginii): \report
  \end{prop}
\end{prop}
\endgroup
