\documentclass{article}
\usepackage{propositions}

%% Helper: a framed label that stretches to fill \labelwidth.
%% The frame makes the allocated label box visible.
%% When the content is wider than \labelwidth the box expands to
%% fit, mimicking standard LaTeX's automatic label-box expansion.
\newlength{\flabelwd}
\newcommand{\flabel}[1]{%
  \settowidth{\flabelwd}{\textbf{#1}}%
  \ifdim\flabelwd<\dimexpr\labelwidth-2\fboxsep-2\fboxrule\relax
    \setlength{\flabelwd}{\dimexpr\labelwidth-2\fboxsep-2\fboxrule\relax}%
  \fi
  \fbox{\makebox[\flabelwd]{\textbf{#1}\hfill}}}

\begin{document}

\section{Per-item dimension keys}

In each test, labels are shown inside an \verb|\fbox| that fills the
entire \verb|\labelwidth|, so the allocated label box is visible.

%%------------------------------------------------------------
\subsection{Baseline: no per-item overrides}

\begin{prop}
  \item[name=\flabel{A}] Default dimensions.
  \item[name=\flabel{B}] Same.
\end{prop}

%%------------------------------------------------------------
\subsection{labelsep override only}

The resolver should derive \texttt{labelwidth} (pos~4), expanding it
when labelsep shrinks and vice versa, preserving the label's left-edge
position.

\begin{prop}
  \item[labelsep=2em, name=\flabel{Wide}] labelsep=2em: box shrinks.
  \item[labelsep=0pt, name=\flabel{Tight}] labelsep=0pt: box expands.
  \item[name=\flabel{Normal}] No override (baseline).
\end{prop}

%%------------------------------------------------------------
\subsection{labelwidth override only}

Resolver should derive \texttt{labelindent} (effectively a no-op since
LI is not a register), or fall through to labelsep.  Since labelsep is
not user-set, it absorbs the deficit.

\begin{prop}
  \item[labelwidth=4em, name=\flabel{W}]
    labelwidth=4em: wider box, labelsep or LI adjusts.
  \item[labelwidth=0.5em, name=\flabel{N}]
    labelwidth=0.5em: tiny box, label overflows it.
  \item[name=\flabel{Def}] Default.
\end{prop}

%%------------------------------------------------------------
\subsection{labelindent override only}

Resolver derives \texttt{labelwidth} (pos~4).  With labelindent=0em the
label sits at the margin; with labelindent=1em it is indented.

\begin{prop}
  \item[labelindent=0em, name=\flabel{Flush}]
    labelindent=0em: label flush with margin.
  \item[labelindent=1em, name=\flabel{Ind}]
    labelindent=1em: label indented, box shrinks.
  \item[name=\flabel{Def}] No override.
\end{prop}

%%------------------------------------------------------------
\subsection{labelindent + labelsep (both per-item)}

Both are user-set, so the resolver must derive \texttt{labelwidth}
(the lowest-priority non-user-set candidate).

\begin{prop}
  \item[labelindent=0em, labelsep=1em, name=\flabel{X}]
    labelindent=0em, labelsep=1em.
  \item[labelindent=0em, labelsep=0pt, name=\flabel{Y}]
    labelindent=0em, labelsep=0pt: box should be wider than X's.
  \item[name=\flabel{Ref}] No override.
\end{prop}

%%------------------------------------------------------------
\subsection{Long label overflow (itemindent derived)}

When the label is too wide for the available space, labelwidth would go
negative.  The resolver skips it and derives \texttt{itemindent}
instead, pushing the first line right.

\begin{prop}
  \item[labelindent=0em, labelwidth=5cm, name=\flabel{Long label}]
    Long label: first line pushed right.
  \item[name=\flabel{OK}] Normal item after overflow.
\end{prop}

%%------------------------------------------------------------
\subsection{Global labelsep respected by per-item resolver}

Here \verb|\propoptions| sets labelsep=1.5em.  A per-item
\texttt{labelindent=0em} override should \emph{not} adjust labelsep
(it is user-set globally); instead \texttt{labelwidth} is derived.

\begingroup
\propoptions{labelsep=1.5em}
\begin{prop}
  \item[name=\flabel{A}] Baseline with global labelsep=1.5em.
  \item[labelindent=0em, name=\flabel{B}]
    Per-item labelindent=0em: labelsep stays 1.5em, labelwidth adjusts.
  \item[name=\flabel{C}] Back to baseline.
\end{prop}
\endgroup

%%------------------------------------------------------------
\subsection{Global labelwidth respected by per-item resolver}

Here \verb|\propoptions| sets labelwidth=3em.  A per-item
\texttt{labelsep=0pt} should \emph{not} shrink labelwidth (it is
user-set globally); instead \texttt{labelindent} absorbs the change
(no visible effect since LI is not a register), or labelsep/itemindent
adjusts.  Since labelwidth is protected, the box stays 3em wide.

\begingroup
\propoptions{labelwidth=3em}
\begin{prop}
  \item[name=\flabel{A}] Baseline with global labelwidth=3em.
  \item[labelsep=0pt, name=\flabel{B}]
    Per-item labelsep=0pt: labelwidth should stay 3em.
  \item[name=\flabel{C}] Back to baseline.
\end{prop}
\endgroup

%%------------------------------------------------------------
\subsection{All three per-item: fallback to default priority}

When labelwidth, labelsep, and itemindent are all set per-item, and
labelindent creates a deficit, the fallback tries them in default
priority order (LW, LS, II) ignoring user-set status.

\begin{prop}
  \item[labelindent=0em, labelwidth=1.5em, labelsep=0.5em,
         itemindent=0pt, name=\flabel{All}]
    All four per-item keys set.  Fallback resolves the deficit.
  \item[name=\flabel{Ref}] Reference item.
\end{prop}
